# 01 Agent Concepts

## LLM App

LLM App 是围绕一次或少数几次模型调用构建的应用。

典型结构：

```text
input -> prompt -> llm -> output
```

它更像“文本生成器”或“语言处理器”。

## Agent

Agent 是一个能根据状态决定下一步动作的系统。

典型结构：

```text
state -> llm decides -> action -> observation -> state update
```

Agent 不一定复杂，但至少要出现以下思想：

- 状态：当前任务、历史、中间结果；
- 决策：下一步做什么；
- 动作：调用工具或影响环境；
- 观察：动作返回的结果；
- 控制流：继续执行或结束。

## 本课判断标准

看到一个系统时，可以问三个问题：

1. 模型是否参与决定下一步动作？
2. 系统是否能调用外部工具或环境？
3. 工具返回结果是否会影响后续回答？

如果答案基本都是“是”，它就开始接近 Agent。
