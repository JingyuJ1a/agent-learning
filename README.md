# Agent Learning

这是一个从零学习 AI Agent 的个人学习仓库，目标是通过「概念学习 + 最小代码实验 + 学习日志沉淀」逐步掌握 Agent 的核心能力。

## 项目目标

- 理解 Agent 与传统 LLM 应用的区别；
- 按阶段学习 Tool Calling、Memory、Planning、Reflection、Router、Multi-Agent 等机制；
- 通过可运行示例与测试，搭建一个可持续迭代的 Agent 学习项目。

## 仓库结构

- `docs/`：学习路线、核心概念与学习日志；
- `lessons/`：每节课的代码与说明；
- `tests/`：最小验证测试。
